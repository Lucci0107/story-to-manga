# MANGA KNOWLEDGE CATEGORIZED PACK

2つの漫画ナレッジを、画面のカテゴリ選択肢に合わせて8カテゴリへ再編したパックです。

| No. | Category | File | 主担当 |
|---:|---|---|---|
| 1 | Style | `01_STYLE_KNOWLEDGE.md` | 画風、色、線、明暗、トーン、効果線、スタイルプリセット、スタイル選択を担当。 |
| 2 | Layout | `02_LAYOUT_KNOWLEDGE.md` | 漫画形式、完成方式、ページ進行、コマ割り、3:4、セーフエリア、読順、カメラ、ページテンプレートを担当。 |
| 3 | Character | `03_CHARACTER_KNOWLEDGE.md` | 人物推定、参考画像割当、人物参照、表情、一貫性、顔・人体・手の品質を担当。 |
| 4 | Genre | `04_GENRE_KNOWLEDGE.md` | 作品ジャンルごとの推奨漫画表現・適用方針を担当。 |
| 5 | Dialogue | `05_DIALOGUE_KNOWLEDGE.md` | 言語、セリフ、ナレーション、吹き出し、擬音・擬態語を担当。 |
| 6 | World | `06_WORLD_KNOWLEDGE.md` | 背景密度、場所の理解、世界・空間情報の見せ方を担当。 |
| 7 | Brand | `07_BRAND_KNOWLEDGE.md` | 作品タイトル、SNS投稿用ストーリー、X向け短縮版など公開時の作品表現を担当。 |
| 8 | Other | `08_OTHER_KNOWLEDGE.md` | 目的、基本原則、AIおまかせ、生成確認、JSON、監査、再試行、状態保持、Security、安全性、優先順位など横断運用を担当。 |

## 分割方針

- 元ナレッジの全 numbered section を8カテゴリへ割り当て。
- 同じ元セクションを複数カテゴリへ重複配置しない。
- 元の規則・用語・優先関係をできるだけ保持。
- 横断ルール（Security、品質監査、JSON、確認フロー等）は `Other` に集約。
