# 変形コマ割り v2（PageComposition v4）

2026-09-22。開始時のmainはf1e5260。添付3ページは、内容や画風を複製する対象ではなく、大小差・内部斜線・矩形外周・明快な読順の参考として確認した。

## 変更範囲

新規Projectの配置既定値をv4にした。保存済みv2/v3は維持し、ネームの「変形コマ割りに更新」で選んだページのみ明示更新する。通常の「配置を再計算」は保存バージョンを維持する。画像API呼出し、Artwork参照・セリフの置換、DB破壊的移行はない。Script Tone、Rendering Style、Knowledge、Storage、WIDE_MULTI_ELEMENTは再実装しない。

- 重要度と文字量を使った非均等面積。主役を独立段に置き、過大な主役段は高さ50%までに調整。
- 意味分類・主役位置・ページ番号から6系統（上部主役／縦アンカー／中段変化／下部クライマックス／非対称会話／心理）を決定。4コマ均等は明示時のみ。
- 斜線は隣接する2コマの共有中心線から生成。物理ページ比3:4を考慮して両岸を平行移動し、一定幅のガターを確保。1ページ最大1共有斜辺（変形2コマ）に抑制。
- 文字100字超のコマは斜線候補から外し、心理ページに斜線を強制しない。
- 最終文字・顔・手・小物の領域で検査し、傾きを100→65→35→18%に減らす。最後は共有する2コマのみ矩形化。他の大小差・配置は保持。
- 通常外周は左/右/上/下の共通安全境界に整列。全文字用の安全帯を持つ既存画像では共有斜線を抑制。
- 明示的なクライマックス・special_emphasis・large-bleed・理由・1コマの条件を満たしたときのみ三辺を裁ち落とす。下部ページ番号帯を保持し、外周を斜めにはしない。
- 旧四角形の外周傾きは描画用コピーで座標を固定し、保存データを変更しない。

## 正規形と安全検証

共有境界、外周境界、最終polygon、bbox、文字位置・保護領域を一つのPageCompositionに保存する。Editor・Preview・PDF・ZIPは既存の共通描画経路を使用する。共有斜線に伴うbbox重複は凸polygonの分離軸判定で区別する。

外周傾き、外周誤差、ガター幅/中心線の不一致、polygonによる文字/重要領域の欠けを追加検出する。既存の楕円・スリバー・文字/顔衝突・読順・crop/contain検査を維持する。生成前監査は新しい境界違反とコマ重複も拒否する。生成承認の設計ハッシュは形状を含むので更新時に再承認が必要になる。

スコアには外周整列・ガター・意味のある動的境界数・面積差・意味面積対応・読順・文字収容・人物安全性を追加した。動的境界0は安全失敗ではない。

## 検証方法

`tests/test_dynamic_layout.py` の33ケースに加え既存回帰を実行。A–D外周固定、E共有斜線、F非対称ページ、G長文、H心理、RTL/LTR、主役面積、4コマ例外、明示bleed、旧版保持、無課金、監査による拒否を含む。

`PYTHONPATH=. .venv/bin/python scripts/dynamic_layout_fixture.py /tmp/manga-dynamic-qa` で会話・アクション・心理・クライマックス・説明・縦アンカーの6ページを非課金生成できる。テストはPreview PNGとZIP画像をバイト比較し、PDF内の画像をRGBピクセル比較する。PDFをPopplerで画像化し全6ページを目視確認した。

Browser QAは専用ローカルDBとデモProviderを使用。Desktop1280px／Mobile390px、Light／Darkでネーム・編集・プレビュー・変形配置への更新を確認。外周が揃い、内部の斜辺と面積差が見える。ページ全体が歪まず、横はみ出し・ブラウザ例外なし。

限界：これは構図の検証。新たな有料画像や画風の品質確認は実行しない。検証図内の色面は人物・顔・手の予約領域を表す。前景を切り抜く新規Inset/Breakoutや任意頂点編集UIは追加せず、既存の安全制約を維持する。
