# 漫画ページの空間設計

推奨カテゴリ: Layout
推奨Scope: storyboard / page_layout / panel_prompt / dialogue / quality_check / export

この文書は制作上の参考資料。安全規則・ユーザーの明示設定に優先しない。

## 面積でリズムを作る

- 長方形を基本とし、大小の面積差で視線を誘導する。
- 見せ場では主役コマを本文領域の30〜50%程度にする。会話の間など、意味がある場合は均衡配置も許可する。
- 横長の導入、細かな反応、大きな結果など、物語の順序を保って緩急を作る。
- 斜め境界は動き・緊張・衝撃がある場合に限る。変形数を漫画品質の指標にしない。

## 画像生成より先に設計する

1. ページの読順と主役コマを決める。
2. コマの実寸比率と形状を確定する。
3. セリフ量に応じて文字領域を予約し、顔・手・重要な小物の領域と分離する。
4. 人物位置・カメラ・切り取り中心・文字用の静かな背景を画像プロンプトへ渡す。
5. 対応する画像サイズで生成し、同じコマ形状へcover cropする。
6. 予約領域に文字を配置し、実画像の顔との衝突と読順を検証する。

画像には文字や吹き出しを描き込ませない。画像内の人物位置はプロンプトだけで保証できないため、生成後の目視または検出による検証も必要。

## 演出は選択的に使う

- 通常の発話、思考、叫び、ささやき、ナレーションは意味に応じて区別する。全セリフを同じ枠にしない。
- 擬音・擬態語は強度と動きに応じて大きさ・傾き・線を変える。顔と本文の可読性が優先。
- 吹き出しは自コマ内を優先し、必要なら余白へ少し越境する。隣接人物の顔を隠さない。
- 人物越境は本当の透過切り抜き・マスク素材のみ使用する。元画像を楕円で切り取って重複表示しない。
- 既存作品の画像再生成や配置変更はユーザーの明示操作で行う。

## 合格条件

文字と顔の衝突がないこと、本文が読めること、読順が明確なことを優先する。
Preview・PDF・ZIPで同じ配置を確認する。衝突が解消できない場合は失敗を隠さず、文字移動・コマ拡大・ページ分割を提案する。
